Como o TI configura e implanta o FolderWorks

1. Defina as Pastas de Rede

No formulário acima, informe o caminho UNC onde está sua pasta MODELO (ex: \\servidor\compartilhamento\MODELO) e a pasta onde ficam os clientes.

2. Conta de Serviço do Active Directory

Informe a conta de serviço autorizada a aplicar permissões NTFS nas pastas de clientes. As credenciais são criptografadas e gravadas internamente no instalador.

3. Compilação do Pacote .MSI

Clique em Gerar Instalador .MSI. O sistema compila o pacote nas máquinas seguras do GitHub Actions. Ao final, basta baixar o arquivo FolderWorks.msi.

4. Distribuição nas Máquinas

Instale manualmente com dois cliques ou distribua silenciosamente para toda a rede via GPO ou Microsoft Intune com o comando: msiexec /i FolderWorks.msi /qn.

Guia do Colaborador: Como usar no dia a dia

1. Criar Nova Pasta de Cliente

Abra o FolderWorks na sua Área de Trabalho, digite o nome ou código do novo cliente (ex: 0123 - Cliente Exemplo LTDA) e clique no botão + Criar Pasta com Modelo. Em 3 segundos a estrutura estará disponível no seu servidor.

2. Mover Pastas com Segurança

Para arquivar ou transferir pastas de clientes encerrados, acesse a aba Mover Pastas. Selecione a pasta de origem e o atalho corporativo de destino. Caso transfira para a pasta errada por engano, você pode clicar em Desfazer para restaurar tudo.

3. Renomear Pastas sem Perder Permissões

Se a razão social do cliente mudar, use a aba Renomear Pasta. O sistema preserva todas as permissões de segurança de cada setor intactas.

Arquitetura On-Premise & Segurança Absoluta

Operação 100% Local (On-Premise)

O FolderWorks não envia nenhum arquivo ou documento corporativo para servidores na nuvem. A comunicação ocorre exclusivamente entre o computador do colaborador e o servidor de arquivos da sua empresa através do protocolo SMB padrão do Windows.

Elevação de Privilégio Restrita (ExecuteAsUser)

Para não dar privilégios de administrador de domínio a todos os usuários da empresa, o FolderWorks executa a aplicação de permissões NTFS utilizando um componente interno assinado (ExecuteAsUser.exe), que roda apenas durante a criação da pasta.

Proteção contra Exclusão e Perímetro

As pastas base da empresa são travadas contra movimentações acidentais. O usuário nunca conseguirá mover acidentalmente a pasta raiz de clientes para o Desktop pessoal ou pendrive.

Perguntas Frequentes (FAQ)

O aplicativo funciona se a internet da empresa cair?

Sim! O FolderWorks roda inteiramente na rede interna (LAN/Wi-Fi corporativo). A internet só é necessária caso a equipe esteja trabalhando via VPN remota.

O usuário comum pode alterar os caminhos do servidor?

Não. As configurações de caminhos de rede e Active Directory são bloqueadas pela compilação do instalador. Para destravar a tela de configurações no app, é exigida a Senha Mestre definida pelo TI.

Preciso instalar Node.js ou Python nas máquinas da equipe?

Não. O pacote gerado (.MSI) é completamente autocontido e traz tudo o que o programa precisa para rodar em computadores com Windows 10 e Windows 11.
