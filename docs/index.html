Como os dados são gravados?

O instalador gerado embute um arquivo criptografado default_config.json no diretório seguro de recursos do aplicativo. Na primeira execução na máquina do usuário, o programa já inicia pronto, sem pedir nenhuma configuração técnica.

Iniciar Compilação no GitHub Actions

Opção 1: Abrir no GitHub Actions (Recomendado)

Abre a página oficial de execução com os parâmetros prontos para você clicar em Run workflow.
